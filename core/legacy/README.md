# StarWork Legacy References

This folder keeps old structures for compatibility research and migration tests.

Current formal Core kits are only:

- `core/kits/project/`
- `core/kits/hub/`

`satellite-starter` is no longer a formal kit. A center-managed project workspace should be represented as:

```text
project workspace + project_center connection
```

The old files under `core/legacy/` should not be offered as user-facing choices.
