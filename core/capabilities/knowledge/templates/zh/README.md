# 项目知识库

这里是当前项目自己的长期知识库。

它不是原始资料夹。用户提供的 PDF、网页、截图、访谈记录和素材应放在参考资料区；这里存放 Agent 整理后的稳定理解、主题知识和综合判断。

开始维护前先读：

1. `schema.md`
2. `index.md`

## 目录说明

- `index.md`：知识地图，只做导航。
- `schema.md`：整理规则，告诉 Agent 什么能进入知识库。
- `log.md`：知识库维护记录。
- `inbox/`：待判断和待整理的知识候选。
- `sources/`：来源索引。
- `pages/`：稳定主题页。
- `synthesis/`：跨主题的策略、复盘和综合判断。
