# Project Knowledge Base

This is the local long-term knowledge base for the current project.

It is not a raw materials folder. PDFs, webpages, screenshots, interview notes, and other source materials belong in the references area. This folder stores stable understanding, topic pages, and synthesized judgment maintained by the Agent.

Read first:

1. `schema.md`
2. `index.md`

## Structure

- `index.md`: navigation map.
- `schema.md`: maintenance rules.
- `log.md`: knowledge maintenance log.
- `inbox/`: candidates waiting to be organized.
- `sources/`: source index.
- `pages/`: stable topic pages.
- `synthesis/`: cross-topic strategy, reviews, and synthesized judgment.
