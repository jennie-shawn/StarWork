# Knowledge Base Decisions

## Accepted

- 知识库是能力，不是 Project Kit 默认目录。
- 一期只做项目本地知识库，不做项目中心共享知识提交。
- `pages/` 是资料触发的稳定主题页。
- `synthesis/` 是问题触发的综合判断。
- CLI 负责稳定结构动作，Skill 负责理解和整理。

## Pending

- 中文路径是否最终确定为 `知识库/`。
- 英文路径是否最终确定为 `knowledge-base/`。
- `starworkKnowledge` 是否默认作为系统级 Skill 安装。
- `init` 是否在交互中询问是否开启知识库。
