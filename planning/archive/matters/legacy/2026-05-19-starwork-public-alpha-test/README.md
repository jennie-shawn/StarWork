# StarWork 公开 A 测分发

## 目标

把 StarWork v0.1 的 CLI、Skills、安装文档和最小测试流程整理到可交给外部 A 测用户验证的状态。

## 范围

- npm 包：`@jennie-shawn/starwork`
- GitHub 仓库：`jennie-shawn/starwork`
- CLI 命令：`starwork`
- 系统 Skills：`starworkInit`、`starworkDoctor`、`starworkMultiagent`
- Kit 自带 Skills：Hub Kit 自带 `starworkSpawn`，单项目 Kit 自带 `neat-freak`
- A 测文档：`product/README.md`、`product/docs/alpha-test-guide.md`、`product/docs/agent-install-guide.md`

## 不在本事项内

- 内容创作者 Pack v0.1 的最终目录、规则和 Demo。
- Course 层交付材料。
- 完整 v0.1 正式发布。
