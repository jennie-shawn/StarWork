# 个人任务管理看板

## 来源

- 来源类型：用户想法
- 提出人 / 来源渠道：用户在 product-planning side conversation 中提出
- 日期：2026-06-01

## 原始描述

后续可以做一个任务管理看板，用于管理用户个人记录的任务。

## 初步理解

这个需求可能是在 StarWork 中增加一个面向个人的任务管理层，让用户可以记录、查看、推进和复盘自己的任务。

它和现有 Agent Lane / 项目规划不同，更偏“用户自己的任务池”或“个人待办看板”。

## 影响范围

- Core：可能需要定义个人任务记录的结构和状态。
- CLI：可能需要新增任务记录、查看、更新、归档相关命令。
- Skill：可能需要一个帮助用户拆任务、整理任务、更新状态的 Agent 工作流。
- Kit / Pack：暂未判断。
- Docs：需要解释个人任务和项目功能规划、Agent Lane 任务的区别。
- 产品体验：可能需要看板视图，用于查看任务状态。

## 当前判断

- 状态：inbox
- 优先级：未判断
- 是否已有相关功能档案：未确认
- 可能归属：新功能，暂名 `personal-task-board` 或 `task-management`

## 下一步

- 继续讨论这个任务看板服务的是“用户个人生活/工作任务”，还是“StarWork 项目内任务”。
- 判断是否应该先进入 `product/planning/features/` 建立功能档案。

## 备注

需要和 Agent Lane 管理看板区分：个人任务看板面向用户自己的任务，Agent Lane 看板面向多 Agent 协作状态和任务分发。
